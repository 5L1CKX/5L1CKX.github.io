Ave Alexandria

Единый пульт автоматизации рабочего процесса компании One control panel for automating a company's workflow

Одна мысль, из которой растёт всё остальное: после совещания не нужно вручную гонять пять инструментов по очереди. Записал разговор — система сама расшифровала, разобрала на артефакты и задачи, показала человеку на проверку, а после согласия занесла задачи в трекер и разослала исполнителям — каждому в свой канал и на своём языке. И всё это видно и управляется из одного окна, где совещания, задачи, люди и проекты связаны графом. One idea everything grows from: after a meeting you shouldn't run five tools by hand. Record the call — the system transcribes it, breaks it into artifacts and tasks, shows a human for review, and once approved pushes tasks into the tracker and dispatches them to executors — each in their own channel and language. All of it visible and managed from a single window where meetings, tasks, people and projects are linked by a graph.

Архитектура: Python-оркестратор (конвейер обработки, граф контекста, состояние в SQLite, FastAPI-API + CLI, headless LLM-раннер) и веб на Vite + React + TypeScript с интерактивным графом на Cytoscape и просмотрщиком документов. Не переписывает готовое, а склеивает проверенные кирпичи (транскрибация, разбор транскриптов, трекер) в один автоматический поток и надстраивает сверху граф и веб. Architecture: a Python orchestrator (processing pipeline, context graph, SQLite state, FastAPI API + CLI, headless LLM runner) and a Vite + React + TypeScript web app with an interactive Cytoscape graph and a document viewer. It doesn't rewrite what works — it glues proven building blocks (transcription, transcript parsing, tracker) into one automatic flow and adds the graph and web on top.
